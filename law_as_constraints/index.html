Law as Constraints

Dylan Waldner

PDF coming soon ← All publications

Abstract

A robot may receive a useful task whose execution is restricted by context-dependent duties and exceptions. We develop a two-rate architecture that uses one defeasible deontic theory for action selection in a learned world-model planner and for geometric and kinematic constraints in a nonlinear model predictive controller. The planner predicts candidate stroke outcomes from visual latents. During execution, the controller re-grounds the theory from exact live observations. It returns observed outcomes and rule-relevant facts to reconcile the planner’s state before the next search. A simulated Franka arm that must inspect and route a package provides a test case. The controller translates a prohibition on package contact with a delivery pad into a heading-dependent half-space. We derive a conditional clearance result for a locked-yaw package and specify paired tests of planner enforcement, controller enforcement, and the state feedback between them. A common audit scores realized events and duties. Historical pilot summaries motivate the evaluation.
